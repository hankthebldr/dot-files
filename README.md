# Dot-Files - Production-Ready CLI for macOS

> A modular, best-in-class configuration system for macOS, optimized for security, performance, and aesthetics.

## Features

- **🚀 Instant Setup**: One-command bootstrap script.
- **🛡️ Security First**: integrated vulnerability scanners, safe aliases, and visual root indicators.
- **🎨 Beautiful UI**: Customized Kitty/Ghostty terminals, Starship prompt, and Nerd Fonts.
- **⚡ Performance**: Lazy-loaded modules, fast startup (<200ms).
- **🔧 Modern Tools**: Replacements for legacy unix tools (`eza`, `bat`, `ripgrep`, `zoxide`, `atuin`).
- **📚 Integrated Help**: Self-documenting aliases and auto-generated docs.

## Quick Start

```bash
# Clone the repository
git clone https://github.com/hankthebldr/dot-files.git ~/.dotfiles
cd ~/.dotfiles

# Run the master bootstrap script
./bootstrap.sh
```

## Daily Usage

### Getting Help

Type `dothelp` in your terminal to see a list of available custom aliases and commands.

### Key Tools

| Command | Tool | Description |
| :--- | :--- | :--- |
| `l`, `ll` | **eza** | Modern, colorful listing with git status |
| `cat` | **bat** | Syntax highlighting and git integration |
| `cd` | **zoxide** | Smart directory jumping |
| `r` | **atuin** | Magical shell history search |
| `dothelp` | **custom** | List all available aliases |

## Structure

- **`bootstrap.sh`**: Master entry point.
- **`shell/`**: Zsh configuration (aliases, exports, security).
- **`terminal/`**: Terminal emulator configs (Kitty, Ghostty, Alacritty) + Starship.
- **`scripts/`**: Installation and utility scripts.
- **`docs/`**: Generated documentation.
