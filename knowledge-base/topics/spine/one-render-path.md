# One render path

> Summary: claw-dashboard.py as the login/default renderer and its fallbacks.

## Context
Login and the default profile must render one dashboard implementation, not
per-surface reimplementations.

## Details
- `scripts/utils/claw-dashboard.py` renders the framed, centered dashboard:
  crisp fastfetch system logo + dense grid + btop-style bars.
- `--quickref` appends the Daily Driver card on the same width engine.
- fastfetch `config-*.jsonc` is the per-profile art + explicit fallback;
  the zsh quickref box is the no-python fallback only.
- Data comes from `ff-readout.sh fields` (including `<res>_pct` for the bars).
- 19 fastfetch configs: 9 generated by `scripts/utils/gen-fastfetch.py`
  (`config.jsonc`, `config-default.jsonc`, 7 core profiles) — never
  hand-edit those (a pre-tool-use hook denies it); 10 specialized ones are
  hand-maintained.
