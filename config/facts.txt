# Open Claw — fact / quote of the day. One per line; # comments and blanks skipped.
The first computer bug was a literal moth, logged by Grace Hopper in 1947.
`ctrl-r` fuzzy-searches your shell history — atuin makes it cross-machine.
`z <partial>` jumps to your most-used dirs; zoxide learns as you go.
SSH multiplexing (ControlMaster) reuses one connection — instant repeat logins.
`!!` reruns the last command; `sudo !!` reruns it with sudo.
A reverse shell is just `nc -e`; a bind shell waits — know which your IDS sees.
`fd` respects .gitignore by default; `fd -H -I` searches everything.
Kubernetes "context" is just a (cluster, user, namespace) tuple in your kubeconfig.
`age` encrypts a file with one public key — no GPG keyring, no keyserver.
The `tee` command splits a pipe: write to a file AND keep it flowing downstream.
`pv` turns any pipe into a progress bar — `pv big.iso | dd of=/dev/sdb`.
Terraform plans are graphs; `terraform graph | dot -Tpng` draws them.
`just` is Make without the tab-vs-space rage. Write a justfile, never look back.
nmap's `-sV` probes service versions; banners lie, so verify before you trust.
`ripgrep` is faster than grep because it skips binary + ignored files by default.
