# Contributing to Dot-Files

We love your input! We want to make contributing to this project as easy and transparent as possible, whether it's:

- Reporting a bug
- Discussing the current state of the code
- Submitting a fix
- Proposing new features

## We use GitHub Flow

All code changes happen through pull requests. Pull requests are the best way to propose changes to the codebase.

## Development Process

1.  Clone the repo.
2.  Create a new branch: `git checkout -b my-new-feature`
3.  Make your changes.
4.  Run tests: `./tests/test-runner.sh`
5.  Commit your changes: `git commit -am 'Add some feature'`
6.  Push to the branch: `git push origin my-new-feature`
7.  Submit a pull request.

## Any questions?

If you have any questions feel free to file an issue.
